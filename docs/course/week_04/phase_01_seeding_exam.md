# Phase I Certification Exam: Seeding the Intent

**Objective:** To verify the candidate's mastery of Phase I (Weeks 1-4) concepts: Intent, Foundation Plates, Green Syntax, and Fact Probes.

---

## Section 1: Intent & Noise (30 Points)

**Q1:** Define the "Signal/Noise Ratio" in the context of SDD. How does high structural noise lead to the "Failure of Intent"? (15 Points)

**Q2:** You are given an AI-generated script that uses five levels of nested factories to print "Hello World."
-   Identify the "Noise" in this script.
-   Propose a SDD Restriction to prevent this specific pattern. (15 Points)

---

## Section 2: Foundations & Roots (30 Points)

**Q3:** What is a "Foundation Plate," and how does it prevent "Sprawling Growth"? (10 Points)

**Q4:** Describe the "Root System" of the QuantaGlia repository. If you add a new script `scripts/empathy_engine.py`, what documentation file *must* you create to prevent "Parasitic Growth"? (10 Points)

**Q5:** In 3D conceptual terms, what does a "Bioluminescent Data-Field" represent in the Greenhouse? (10 Points)

---

## Section 3: Technical Syntax & Probes (40 Points)

**Q6:** Write a Green Syntax reasoning gate for a module that must calculate "Neuro-Flow."
-   Requirements: Must use the `numpy` tool.
-   Forbidden: Any use of the `global` keyword.
-   Limits: Total function length must be under 20 lines. (15 Points)

**Q7:** Explain the difference between an "Immutable Fact" and a "Volatile Fact." Give an example of each from the `pruner` logic. (10 Points)

**Q8:** **Practical Design:** Conceptualize a **Probe (Card)** to detect "Emotional Resonance" in a 3D environment.
-   What does the probe measure?
-   What single **Fact** does it report to the Registry?
-   How would a failure of this fact impact the "Irrigation" of the code? (15 Points)
