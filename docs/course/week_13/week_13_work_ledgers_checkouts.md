# Week 13: Work Ledgers & Checkouts—Audit Trails and Verification

## 1. The Work Ledger
In the Greenhouse, "I'm done" is not a valid state. Completion is only achieved through the **Work Ledger**.
-   **Checkin:** The intention. "I am seeding a new neuroplasticity module."
-   **Checkout:** The proof. "All Sips passed, the `neuro_flow` fact is `0.92`, and the Fact Lock is released."

## 2. The Audit Trail
The Audit Trail is a time-series record of the Fact Registry. It allows us to see how the "Greenhouse" has grown over time.
-   **Verification:** Comparing the current state to the historical "Healthy Baseline."

## 3. 3D Vision: Time-Lapse Growth
Use the "Time-Slider" in your 3D environment to watch the Greenhouse evolve. You can see the trellises being built, the code vines growing, and the occasional pruning of a dead branch.

## 4. Lab: Generating a Checkout
1.  Complete a minor refactor of a documentation file.
2.  Run a validation script.
3.  Manually draft a "Checkout" report that includes the timestamp, the agent ID, and the change in the Fact Registry.
