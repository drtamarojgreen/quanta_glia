# The Architect's Lexicon: A Master Glossary for CDD

## Technical Primitives

-   **Audit Trail:** A persistent log of changes to the Fact Registry used for debugging environmental "wilting."
-   **Card:** A CDD Class or script that acts as a structural probe.
-   **CDD (Chai Driven Development):** A development methodology prioritizing structural restrictions over behavioral requirements.
-   **Fact:** An immutable or state-based unit of truth stored in the Registry.
-   **Green Syntax:** The machine-readable grammar used to define CDD restrictions and reasoning gates.
-   **Reasoning Gate:** A validation step where AI-proposed logic is checked against structural constraints before code generation.
-   **Sip (Small Integration Procedure):** A single, atomic execution of a Card to verify a specific environmental condition.
-   **Situation:** The global environmental context defining allowed tools, constants, and limits.

## Greenhouse Metaphors

-   **Environmental Contamination:** When a bug or faulty architectural pattern spreads across the system due to a failed Sip.
-   **Environmental Wilt:** A general state of system regression or technical debt.
-   **Foundation Plate:** The 3D spatial and complexity boundary for a module.
-   **Neural Greenhouse:** The integrated development environment where mental health simulations are cultivated.
-   **Parasitic Growth:** Unnecessary abstractions or code without a corresponding "root" in documentation.
-   **Root System:** The interconnected documentation (`docs/`) and scripts (`scripts/`) that provide the foundation for growth.
-   **Seeding:** The initial phase of defining intent and restrictions.
-   **Trellis:** The set of structural restrictions that guide and bound the growth of code.

## 3D & Psychological Terms

-   **High Fidelity:** A state of high resolution and detail, both in code quality and 3D visualization.
-   **Neuroplasticity Simulator:** A specific module designed to model the brain's ability to reorganize itself.
-   **Panic Deceleration:** A design pattern for transitioning from high-stress to calm states.
-   **Structural Noise:** Excessive complexity that obscures the core intent of a module.
-   **The Signal:** The core psychological purpose or "truth" of a system.
